## 서비스 인프라 분리 및 비용 최적화

2026.01 – 2026.02\
AWS · Claude Code

두 서비스가 단일 AWS 계정과 인프라를 공유하고 있었습니다. 각각 별도로 운영되기 시작한 뒤에도 리소스가 혼재되어 있어, 서비스별 비용을 파악할 수도 독립적으로 운영할 수도 없는 구조였습니다.

전체 리소스의 의존 관계를 분석해 인프라를 재설계했습니다. EC2와 RDS 스펙을 실제 사용량 기준으로 조정하고, 비용 효율이 낮은 API 서버는 서버리스 아키텍처로 전환했습니다. 반복되는 운영 작업은 Claude Code 기반 AWS 관리 킷(infra-as-claude)을 직접 만들어 자동화했습니다.

월 AWS 비용을 100만원에서 50만원으로 줄이고, 두 서비스의 독립 운영 체계를 세웠습니다.

## Arduino 컴파일 서버 Node.js → Go 마이그레이션

2025.11 – 2025.12\
Go · Gin · Arduino CLI · Docker

컴파일 서버가 Node.js 단일 스레드 구조라, 학생들이 동시에 접속하는 수업 환경에서 최대 대기 시간이 120초에 달하는 병목이 있었습니다.

Go 고루틴 기반으로 서버를 재설계하고 세마포어로 동시 처리 상한을 제어했습니다. 기존 Node.js API와 완전히 호환되는 응답 포맷을 유지한 채 프로덕션에 배포했고, 병렬 운영 기간을 두어 단계적으로 트래픽을 전환했습니다.

응답 시간을 120초에서 11초로 90% 단축했습니다. 메모리는 200MB에서 3MB로 줄었고, 서버는 2대에서 1대로 축소했습니다.

## 글로벌 개발팀 인프라 운영

2025.07 – 2026.03

한국·카자흐스탄·카타르·러시아 개발자가 참여하는 글로벌 팀의 AWS 인프라를 단독으로 담당했습니다. 월간 개발자 미팅을 기획·운영하며 라이트닝 톡과 기술 공유 세션을 진행했습니다.
