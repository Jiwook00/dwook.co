## dwook.co

지금 보고 계신 이 사이트입니다. 티스토리나 벨로그 같은 외부 플랫폼 대신, 직접 운영하며 이력서와 포트폴리오를 겸하는 개인 블로그를 만들었습니다.

### 만든 이유

기술 글, 자기소개, 사이드 프로젝트를 한곳에서 보여주고 싶었습니다. 무엇보다 관리 비용을 최소로 유지하면서도 취향이 반영된 공간을 갖고 싶었습니다.

### 기술 스택

- **Astro** — JS를 거의 보내지 않는 정적 사이트 생성기
- **Tailwind CSS** + **TypeScript**
- **Pagefind** — 빌드 타임 정적 검색 인덱스
- **Giscus** — GitHub Discussions 기반 댓글
- DB·백엔드 서버 없음. 글쓰기는 로컬에서 마크다운을 쓰고 git push하면 끝.

베이스 템플릿으로 [astro-micro](https://github.com/trevortylerlee/astro-micro)를 사용했습니다.
