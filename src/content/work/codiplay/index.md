## 서비스 인프라 분리 및 비용 최적화

2026.01 – 2026.02\
AWS (EC2, RDS, Lambda, VPC, CloudWatch) · Claude Code

- **문제 상황**
  - 법인 분리 전부터 코디플레이 AWS 계정 안에 마로마브 서비스 리소스와 공용 리소스가 섞여 있어, 서비스별 비용 파악과 독립 운영이 어려움
  - 서버 스펙이 실제 사용량보다 크게 잡혀 있고, 쓰지 않는 리소스가 비용을 계속 발생시킴
- **해결 과정**
  - 공용 리소스의 서비스별 의존 관계를 파악해 계정별로 분리하고, 병행 운영으로 검증한 뒤 전환
  - 미사용·고비용 리소스를 정리하고, EC2를 수업 스케줄의 피크를 감당하는 최소 사양으로 조정
  - 호출량이 적은 내부·베타 서비스는 서버리스로 전환해 무료 사용량 안에서 운영
  - Claude Code 기반 AWS 관리 킷(infra-as-claude)을 직접 개발해 반복 운영 작업을 자동화
- **주요 성과**
  - 코디플레이 계정 월 AWS 비용 100만원 → 50만원 (분리 전 2개월 vs 분리 후 2개월)

## Arduino 컴파일 서버 Node.js → Go 마이그레이션

2025.11 – 2025.12\
Go · Gin · Arduino CLI · Docker · Claude Code

- **문제 상황**
  - 교육용 블록 코딩 플랫폼의 컴파일 서버가 요청마다 arduino-cli 자식 프로세스를 동시 실행 상한 없이 실행
  - 한 반(30명)이 동시에 컴파일하면 프로세스들이 CPU를 두고 경합해 평균 응답 시간이 120초까지 늘어남
  - 수업 시간대마다 서버를 증설해 버티는 구조
- **해결 과정**
  - Go로 컴파일 서버를 새로 만들고, 세마포어로 동시 컴파일 수에 상한을 두어 초과 요청은 대기열에서 순서대로 처리
  - 기존 Node.js API와 같은 응답 포맷을 유지하고, 병렬 운영 기간을 두어 단계적으로 트래픽 전환
- **주요 성과**
  - 30명 동시 컴파일 요청 기준 평균 응답 시간 120초 → 11.6초 (동일 사양 서버 비교)
  - 수업 시간대 증설 없이 서버 2대 → 1대로 운영
