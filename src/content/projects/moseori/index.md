## 모서리

읽은 책을 책장에 꽂고, 좋았던 문장을 쪽수와 함께 옮겨 적고, 거기에 생각을 덧붙이는 웹입니다. 이름은 접어둔 페이지 모서리에서 가져왔습니다.

### 만든 이유

책을 읽으며 좋았던 문장을 쪽수와 함께 적고, 왜 남겼는지를 같이 기록하는 습관을 노션으로 관리해 왔습니다. 기존 독서 기록 앱들은 필요 없는 기능이 많아, "읽은 책을 기록한다"는 것만 남긴 전용 도구로 옮겼습니다.

### 주요 기능

- **책장** — 알라딘 API로 책을 검색해 담고, 읽고 싶음 / 읽는 중 / 읽음 / 덮어둠 상태로 나눠 표지 갤러리로 봅니다.
- **밑줄** — 문장과 쪽수를 기록하고, 하나의 밑줄에 여러 개의 생각을 덧붙입니다. 전체 밑줄만 따로 모아 볼 수 있습니다.
- **오늘의 밑줄** — 하루 동안 고정되고, 오래 보지 않은 밑줄을 먼저 꺼냅니다.
- **리뷰·별점** — 책당 하나의 리뷰와 5점 별점.
- **키보드 단축키** — `⌘K` 검색, `⌘↵` 저장, 문장↔쪽수 이동. 밑줄을 연달아 옮겨 적는 흐름이 끊기지 않게 했습니다.

### 기술 스택

- **Next.js 16 (App Router)** · React 19 · TypeScript · **Tailwind CSS v4**
- **Supabase** — Google OAuth, Postgres(RLS), Storage
- **알라딘 TTB API** — 책 검색·표지·대표색 추출
- **Vercel** 배포
