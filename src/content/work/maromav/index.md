## Firebase → PostgreSQL 마이그레이션 및 API 서버 재구축

2021.09 – 2021.12\
NestJS · PostgreSQL · Firebase

Firebase(NoSQL) 기반으로 운영되던 서비스에서 복잡한 관계형 데이터 처리의 한계가 명확해졌습니다. 별도 API 서버 없이 클라이언트가 Firebase에 직접 접근하는 구조라 확장에도 문제가 있었습니다.

비정형 데이터를 관계형으로 재설계하며 PostgreSQL 스키마를 설계하고, NestJS 기반 RESTful API 서버를 구축했습니다. 마이그레이션 전 과정에 로깅을 적용해 데이터 누락을 실시간으로 확인하며 전환을 마쳤습니다.

데이터 누락 없이 마이그레이션을 완료했고, 관계형 DB 기반 API 서버로 이후 기능 개발의 토대를 마련했습니다.

## 웹/앱 서비스 백엔드 개발 및 인프라 운영

2022.01 – 2025.07\
AWS · GitHub Actions · Prometheus · Loki · Grafana

교육 플랫폼의 백엔드 API 개발과 AWS 인프라 구축·운영을 맡았습니다. GitHub Actions와 AWS CodeDeploy로 무중단 자동 배포 파이프라인을 구성하고, Prometheus·Loki·Grafana 기반 모니터링 환경을 만들었습니다. 사내 발표 문화(24절기톡)를 기획·운영하며 개발·디자인 등 다양한 주제의 정기 발표를 이어갔습니다.
